# Pulse Strike · 张三的小游戏

浏览器可玩的 **Valorant 风格 3D 第一人称射击演示**：选特工、选地图、打本地 AI，先赢 3 回合。

无联网、无账号；Three.js + 静态页面，方便本地或 Cloud Agent 演示。

## 如何运行

```bash
npm start
# 或
python3 -m http.server 8765
```

浏览器打开 <http://localhost:8765>（需 HTTP，不要用 `file://`）。

## 操作

| 按键 | 作用 |
|------|------|
| WASD | 移动 |
| Shift | 冲刺 |
| 鼠标 | 视角（点击画布锁定） |
| 左键 | 射击 |
| R | 换弹 |
| Q | 特工技能 |
| Esc | 暂停 / 返回菜单 |

## 特工

1. **BLITZ** — 闪光：致盲附近敌人约 2.5 秒  
2. **VAPOR** — 烟雾：准星落点生成烟雾墙约 8 秒  
3. **SURGE** — 冲刺：向前突进并少量回血  

## 地图

1. **YARD** — 开阔庭院、木箱掩体、暖色雾效  
2. **CORRIDORS** — 工业走廊、狭道交火、冷色灯光  

## 对局规则

- 每回合歼灭场上全部 BOT  
- 先赢 **3** 回合获胜；死亡则对方拿下该回合  
- HUD：生命、弹药、技能冷却、比分、小地图
