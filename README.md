# Pulse Strike · 张三的小游戏

浏览器可玩的 3D 射击：**练习打 AI**，或 **开房和朋友 1v1**。

## 在线试玩（公网）

**打开：<https://indigo-mantle-gexy.here.now/>**

### 联机三步

1. 双方打开同一链接  
2. 房主：选特工/地图 → **开房** → **生成房间号** → 发给好友 → 对方加入后点 **开始**  
3. 加入方：选特工 → **加入** → 输入房间号 → 等房主开始  

技术：PeerJS + WebRTC，无需自建服务器。建议 2 人；断线请重开房间。

### 键位

右上角 **键位**、开始下方「自定义键位」、暂停菜单均可改键。

## 特工（冷却均为 5 秒）

1. **BLITZ 闪光** — 致盲  
2. **VAPOR 烟幕** — 烟雾  
3. **SURGE 疾风** — 冲刺  

## 地图

1. **庭院 YARD** — 开阔掩体  
2. **走廊 CORRIDORS** — 狭道近战
