# 尖锋战术（SpikeTactics）

原创回合制战术 FPS 网页原型（Three.js + Vite）。灵感来自战术射击品类结构，角色 / 技能 / 地图均为原创。**支持手机浏览器 / PWA 手游操作**。

## 在线试玩（公网）

**https://solar-tablet-mwys.here.now/**

打开链接 → 选特工 → 开始对局。手机建议横屏；可加 `?mobile=1` 强制手游控件。

> 当前托管为 here.now 匿名发布（约 24 小时过期）。Claim：https://here.now/c/KAJVkBrsnReKUjas  
> 本地开发仍可用下方命令。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 <http://localhost:5173>）。

生产构建：`npm run build` → `npm run preview`。

## 手机操作（手游）

| 控件 | 作用 |
| --- | --- |
| 左摇杆 | 移动 |
| 右侧滑动 | 瞄准（无需鼠标锁定） |
| 开火 | 射击（按住连发） |
| 换弹 | 换弹 |
| 跳 / 冲刺 | 跳跃 / 加速 |
| 技能按钮 | 闪风 / 雾隐 技能与大招 |
| 互动 | 按住：安放 / 拆除 / 拾取爆弹器 |
| 商店 | 购买阶段开关商店 |

PWA：安装 `manifest.webmanifest` + 图标，支持「添加到主屏幕」。移动端自动关闭阴影并限制像素比以降低 GPU 负担。

## 桌面操作

| 按键 | 作用 |
| --- | --- |
| WASD | 移动 |
| Shift | 冲刺 |
| 鼠标 | 瞄准（点击画面锁定） |
| 空格 | 跳跃 |
| 左键 | 射击 |

| Q / E / C | 特工技能 |
| X | 大招（击杀积攒） |

| B | 购买阶段开关商店 |
| Esc | 释放鼠标 |

## 本局内容

- **地图「裂港」**：A / B 双包点、中路与侧路掩体
- **爆弹器**：安放、拆除、爆炸判胜
- **回合 + 15 秒购买 + 信用点经济**（短焰 / 迅蝎 / 弧光 / 近狩 + 轻甲 / 重甲）
- **特工**：闪风（疾闪 / 耀光 / 踏风 / 破锋）、雾隐（雾墙 / 焰障 / 霾团 / 天幕）
- **3 个人机**：按攻防职责推进包点或守点
- 先到 **5** 分结束对局（原型缩短；完整规则见 GDD 的 13 分）
