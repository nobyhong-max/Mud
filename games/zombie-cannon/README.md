# 尸潮炮阵

手机浏览器可玩的竖屏塔防射击小游戏：底部固定炮塔向上开火，抵御一波波逼近基地的卡通僵尸。玩法灵感来自「打僵尸 + 选强化」类休闲射击，**名称、美术与 UI 均为原创**，不沿用任何商业产品的素材或商标。

## 试玩

构建后可将本目录发布到 here.now 或任意静态托管；入口为 `index.html`。

## 操作（触屏）

| 操作 | 说明 |
|------|------|
| 拖动屏幕 | 调整炮口瞄准方向（带轻微自动辅瞄） |
| 右下角「开火」 | 按住连射 |
| 强化弹窗 | 每击杀 10 只僵尸三选一 Roguelike 强化 |

## 规则摘要

- 僵尸从上方刷出，碰到底部防线会扣基地生命；基地归零则游戏结束。
- 清完当前波次自动进入下一波（血量、速度递增），波次清空有加分。
- 强化包括：伤害、射速、穿透、减速、额外弹丸、基地回复、溅射、辅瞄等。

## 本地预览

任意静态服务器打开本目录即可，例如：

```bash
python3 -m http.server 8765 --directory games/zombie-cannon
```

## 与仓库其他游戏

本游戏位于 `games/zombie-cannon/`，不影响仓库根目录或其它 `games/*` 子项目。
