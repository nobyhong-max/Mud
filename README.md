# 尖锋战术 · 简易 FPS

最小可玩浏览器第一人称射击原型（Three.js + Vite）。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端里显示的本地地址（默认 <http://localhost:5173>）。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD | 移动 |
| 鼠标 | 瞄准（点击开始后锁定） |
| 空格 | 跳跃 |
| 左键 | 射击 |
| R | 换弹 |
| Shift | 冲刺 |
| Esc | 释放鼠标 |

## 内容

- 小型方盒竞技场 + 掩体
- 4 个可射击的移动靶（机器人）
- 生命 / 弹药 HUD

无联网、无技能、无经济——只为几分钟内能玩起来。
