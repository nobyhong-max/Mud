# 联机打怪 RPG / Mud Multiplayer Mini-RPG

浏览器多人联机 2D 小游戏：**俯视角地图探索**与**独立横版战斗界面**分离，个人经验等级、宠物蛋、首领解锁地图。

## 运行 / Run

```bash
cd game
npm install
npm start
```

浏览器打开 **http://localhost:3847**（可开多个标签页模拟多人）。

## 两种模式 / Two Modes

### 1. 探索模式（Overworld）

- **2D 俯视角** Canvas 地图：移动、看见同地图其他玩家、拾取宠物蛋。
- 怪物在地图上游荡，**不会在探索界面直接扣血或攻击**。
- **进入战斗**：走近怪物（碰撞/仇恨范围）、或 **点击怪物**。
- 操作：WASD 移动；点击地面上的蛋拾取；右侧地图传送（需已解锁）。

### 2. 战斗模式（Battle Screen）

- 触发战斗后切换到 **全屏独立战斗面板**（横版 2D 对阵画面 + 血条 + 战报），探索画布变暗。
- **你 + 宠物** 对 **单只敌人/首领**；实时节奏（非回合制）：按冷却自动交锋。
- **攻击**：按钮或空格；宠物自动参战。
- **逃跑**：普通怪物可逃（首领战不可逃）；失败或逃跑后回到探索地图，敌人以当前血量重新出现（若未击杀）。
- 击杀后关闭战斗界面，回到探索；经验、掉落、首领解锁在服务端结算。

## 操作一览

| 场景 | 操作 |
|------|------|
| 探索移动 | WASD |
| 发起战斗 | 靠近怪物 / 点击怪物 |
| 战斗攻击 | 空格 或「攻击」按钮 |
| 战斗逃跑 | 「逃跑」按钮（非首领） |
| 拾取宠物蛋 | 探索模式下点击蛋 |
| 换地图 | 右侧列表（非战斗且已解锁） |

## 玩法概要

1. 输入昵称加入；同地图玩家实时可见（战斗中你暂时从他人视野隐藏）。
2. 击杀获得 **个人经验**；升级提升生命与攻击。
3. 怪物随机掉 **宠物蛋**；拾取孵化，宠物在 **战斗界面** 协同攻击。
4. 清空小怪后右侧 **首领区域** 刷新 BOSS；首领战同样进入独立战斗界面，击败后解锁下一地图。
5. 地图：**新手草原** → **幽暗森林** → **熔岩洞窟**。

## 技术栈

- Node.js + Express + Socket.IO（权威服务端）
- 探索：俯视角 Canvas；战斗：独立横版 Canvas + DOM 面板

## 已知限制

- 服务端重启不保留进度
- 战斗为个人实例（同一只怪同时只能被一名玩家拉入战斗）
- 无移动端虚拟摇杆

## English (brief)

2D top-down multiplayer exploration plus a **separate side-view battle UI**. Walk up to or click monsters (and bosses) to enter combat; win to return to the map with XP/loot. Three zones, pets, Chinese UI.
