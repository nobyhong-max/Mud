# Pulse Strike · 张三的小游戏

浏览器可玩的 **Valorant 风格 3D FPS**：练习打 BOT，或 **PeerJS 联机开房** 1v1。

## 在线试玩（公网）

**打开：<https://indigo-mantle-gexy.here.now/>**

### 联机怎么玩

1. 双方打开同一公网地址  
2. **房主**：选特工/地图 → 点「联机开房」→「创建房间」→ 把 **4 位房间号** 发给好友 → 好友加入后点「开始联机对局」  
3. **加入方**：选特工 →「加入房间」→ 输入房间号 →「加入」→ 等待房主开始  

技术：浏览器 WebRTC（PeerJS 公共信令）。**无需自建服务器**即可联机。限制：建议 2 人、依赖 NAT/防火墙、公共 broker 可用性；断线需重开房间。练习模式仍可单机打 AI。

可选本地静态服（开发用，非正式测试链接）：`npm start`

### 键位

主菜单右上角 **⌨️ 键位**、开始按钮下方「打开键位设置」、暂停菜单均可改键；写入 `localStorage`。
