# 尖锋战术（SpikeTactics）

原创回合制战术 FPS 网页原型（Three.js + Vite）。灵感来自战术射击品类结构，角色 / 技能 / 地图均为原创。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 <http://localhost:5173>）。

生产构建：`npm run build` → `npm run preview`。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD | 移动 |
| Shift | 冲刺 |
| 鼠标 | 瞄准（点击画面锁定） |
| 空格 | 跳跃 |
| 左键 | 射击 |
| R | 换弹 |
| Q / E / C | 特工技能 |
| X | 大招（击杀积攒） |
| F | 安放 / 拆除 / 拾取爆弹器（按住） |
| B | 购买阶段开关商店 |
| Esc | 释放鼠标 |

## 本局内容

- **地图「裂港」**：A / B 双包点、中路与侧路掩体
- **爆弹器**：安放、拆除、爆炸判胜
- **回合 + 15 秒购买 + 信用点经济**（短焰 / 迅蝎 / 弧光 / 近狩 + 轻甲 / 重甲）
- **特工**：闪风（疾闪 / 耀光 / 踏风 / 破锋）、雾隐（雾墙 / 焰障 / 霾团 / 天幕）
- **3 个人机**：按攻防职责推进包点或守点
- 先到 **5** 分结束对局（原型缩短；完整规则见 GDD 的 13 分）
